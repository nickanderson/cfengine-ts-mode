#+TITLE: Changelog

* 0.1.0 (unreleased)

First release.

- Font lock from the tree-sitter-cfengine grammar, following the Zed extension's =highlights.scm=, plus ~$(var)~ and ~@(list)~ references inside strings and bare bundle and body references as calls
- Indentation that matches ~cfengine format~, checked against every policy file in masterfiles (~make corpus~)
- ~cfengine-ts-mode-format-buffer~ (~C-c C-f~), ~cfengine-ts-mode-format-region~ (~C-c C-r~) and ~cfengine-ts-mode-format-on-save~, using ~cfengine format~
- A Flymake backend and a Flycheck checker for ~cfengine lint~, linting with the rest of the policy tree in strict mode when the file is in one
- Indentation while typing incomplete code, and comments that follow the code typed after them
- Completion of promise types, attributes, option values and body and bundle names from the ~cf-promises~ syntax, and ElDoc for attributes
- Completion of variables in ~$(...)~ and class names in guards and class expressions, from the policy tree and ~cf-promises~; ~M-.~ on variables and classes
- Custom promise types defined by ~promise~ blocks: completion of the type, of its attributes and of the block's own, ~M-.~ and ~C-c C-d~
- ~cfengine-ts-mode-browse-docs~ (~C-c C-d~) opens the reference documentation for the thing at point
- Completion of built-in function names and ElDoc signatures, from =cfengine.el=
- Jump to bundle and body definitions and list references (~M-.~, ~M-?~) across the policy tree
- Imenu, defun and sentence movement, ~which-function~, and outline folding of blocks and bundle sections
- Opens =.cf= and =.cf.sub= files that contain a block header, and remaps ~cfengine-mode~ and ~cfengine3-mode~ when the grammar is installed
- ~cfengine-ts-mode-install-grammar~ builds and installs the grammar
